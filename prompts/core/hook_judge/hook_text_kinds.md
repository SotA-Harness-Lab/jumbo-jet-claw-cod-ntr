The hook's text is either a condition that must hold, such as "All unit tests pass", or a rule about what to block or allow, such as "Block any Bash command that reads .env files". A condition is met when it holds. A rule is met when the input is not something the rule blocks, and is something it allows where it names what to allow: when the input is what a rule blocks, the rule is not met. On a hook that runs when the agent is about to stop, not met means the agent has to keep working.
